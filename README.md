# 明策 MINGCE · 自然语言选股与策略解释器

把“经营改善、估值合理、走势相对稳定”转成用户能检查、修改和执行的条件，解释股票为何入选、排除或无法判断，并比较条件变化的影响。用于研究，不输出涨跌预测、收益承诺或直接买卖建议。

- **Web 产品：** https://mingce-stock-lab.justslug1.chatgpt.site/
- **源代码：** https://github.com/lzy75/mingce-stock-lab
- **提交说明：** [SUBMISSION.md](docs/SUBMISSION.md)
- **最终验收：** [FINAL_ACCEPTANCE.json](docs/FINAL_ACCEPTANCE.json)

## 快速体验

1. 在宽大的输入框描述偏好，或选择场景，点击“用 AI 拆解我的策略”。
2. 核对模糊词的代理定义、单位和阈值；编辑条件，确认后执行。
3. 查看入选、排除、无法判断及逐条件证据；修改阈值，查看同快照的名单变化。
4. 比较2—4只股票、保存策略或导出；可在“策略推演”运行边缘场景。

真实数据演示：切到“真实数据”，输入“市盈率大于0倍，市盈率低于25倍”，核对条件后执行。2026-10-20用户已在公开网页完成该链路并提供截图：12只研究池，11入选、1排除、0无法判断，获取与证据时间可见。这是该时点的验收结果，不是当前市场结论。

**已知网络限制：** 同期GitHub独立运行器调用扶摇出现超时/522，本机直连及用户实际浏览器成功；不同访问路径的表现存在差异，不能保证持续可用。上游失败会明确报错，不生成新的正常名单，不将旧快照冒充最新数据。

## 产品与职责边界

| 层 | 职责 |
|---|---|
| AI | 核对自然语言条件、解释模糊词的可操作代理；输出经过结构与约束一致性校验 |
| 确定性引擎 | AND条件编译、单位校验、冲突检测、三态筛选、同快照条件差异 |
| 金融数据工具 | 通过扶摇官方MCP读取数据，提供原始字段、来源、时点、单位、口径与请求ID |
| 用户 | 核对代理定义、修改阈值、确认研究范围后执行 |

明确条件不能被模型静默遗漏、禁用、增改；未知要求、错单位、冲突和不支持的窗口先阻止。模型失败不静默回退成正常AI结果。无模型配置时明确显示本地规则模式。偏好推荐提供研究条件模板，不自动执行或推荐买卖。

## 本地运行

应用需Node.js 24；自动测试另需Python 3，用于执行生成脚本的本地API替身测试。

```bash
npm ci
cp .env.example .dev.vars
# 在.dev.vars中填写服务端授权，禁止提交真实值
npm run dev
```

默认地址`http://127.0.0.1:5173`，以终端输出为准。`npm run build`构建到`dist/`；`npm start`运行本地Worker预览。项目使用React、Vinext与Cloudflare Workers，保留Sites构建适配。

| 服务端变量 | 用途 |
|---|---|
| `FUYAO_API_KEY` | 扶摇数据授权 |
| `FUYAO_TRANSPORT` | 默认`mcp`，可显式设为`rest`；证据展示实际传输 |
| `AI_API_KEY` | 模型授权；线上已配置DeepSeek官方服务 |
| `AI_BASE_URL` | OpenAI兼容服务根地址 |
| `AI_MODEL` | 实际可用的模型名称，配置模型时必填 |

密钥仅放本机忽略文件或托管服务端Secret，不使用`NEXT_PUBLIC_`/`VITE_`前缀。公开URL无需评审者提供Key。GitHub保存源码；服务端托管保护授权，纯GitHub Pages不能独立承担这部分调用。

## 数据、指标与口径

数据优先使用题目推荐的[扶摇官方API/MCP](https://fuyao.aicubes.cn/docs/)，MCP端点为`https://fuyao.aicubes.cn/mcp/a-share`，执行初始化、工具发现及只读调用。iFinD未接入，未以未经验证的来源替换。

支持15项指标：PE TTM、PB MRQ、PS TTM、PCF TTM、营收同比、归母净利润同比、最新价、涨跌幅、成交额、成交量、振幅、20日年化波动率、20日涨幅、20日最大收盘回撤、20日均线偏离；提供6类研究场景。

- 默认12只起步研究池，可自行粘贴更多代码；20只是单批传输大小，不是总量上限。分批全部完成并核对代码覆盖后才生成新结果。
- 财报同比比较最近可用已披露累计报告期与上年同期；基数非正、缺失或冲突时不生成正常同比。
- 趋势指标使用此前21个完整交易日的前复权收盘，排除当日；波动率为20个简单日收益率的样本标准差×√252×100。
- 行情与估值时点是上游响应批次时间，不证明每股独立新鲜；界面分别展示获取时间和证据时间。交易时段/应有收盘时点滞后15分钟、财报期末超过200天时提示核查。
- 行情/估值缓存60秒，财报6小时，历史/日历1小时；页面可见且开启自动刷新时每60秒尝试更新，不保证逐笔实时。
- 缺失、过期、冲突和不适用为无法判断；明确失败优先，但逐条件证据仍保留。不同快照不把名单变化全部归因于条件变化。

## 已知边界与未做事项

1. 只筛选用户指定研究池，非自动全A股扫描；没有行业、ST、停牌过滤，不支持任意新闻/行业要求或任意统计窗口。
2. 已完成比较、本地保存、条件变化解释与导出；未做回测或后台监控。保存使用浏览器localStorage，无跨设备账户存储。
3. 批次时间不代表逐股时间，缓存和上游服务影响新鲜度；内存限流为单Worker实例尽力实现。
4. SuperMind研究板块的脚本创建、回读、重复执行和冲突拒绝已在官方远端验证；同花顺行情客户端分组未显示，网页一键账户写入未实现。这是扩展功能，不列为原题必交完成项。
5. 独立网络出现上游超时/522，用户实际浏览器已通过一次真实链路；详细区分见最终验收，不能解释为持续可用性承诺。
6. 未制作可选演示视频；题目24小时时限需由本人按实际开始与提交时间确认。
