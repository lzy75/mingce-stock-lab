# 明策 MINGCE · 自然语言策略研究台

将“经营改善、估值合理、走势稳定”等研究意图转换为可检查、可修改、可执行的条件。每个入选、排除和无法判断的结果都可展开证据。研究用途，不提供收益承诺、确定性预测或直接买卖建议。

**在线网页：** https://mingce-stock-lab.justslug1.chatgpt.site

**GitHub：** https://github.com/lzy75/mingce-stock-lab

## 快速体验
1. 首屏导览可选择6类研究场景，输入描述、预览构造示例；向下进入原研究台。
2. 修改研究描述，点击“用 AI 拆解我的策略”或“拆解为筛选条件”。检查模糊词代理定义、阈值和范围。
3. 勾选确认，执行筛选。切换入选、排除、无法判断分组，点击股票展开原始证据。
4. 改阈值后再次确认执行，查看同快照新增/移出；选择2—4只比较，或保存策略。
5. 切换真实模式，使用服务端扶摇授权读取所选A股研究池的最新可得数据。
6. 打开“策略推演”，对照10个示例及corner case的预期与实际，拖动PE滑块观察同快照名单变化，注入缺失、过期、冲突或限流。
7. 点击“研究视图”切换日间/夜间、紧凑/舒展和动态；按主动偏好获得可解释模板。
8. 在“方法与口径”运行三组真实案例验收，下载模型ID、MCP追踪与三态结果；在同花顺导出面板复制问财条件，或生成SuperMind自选板块脚本；脚本需要本人在目标平台检查后运行。

## 本地启动
需要 Node.js 24（运行原生TypeScript测试；应用引擎最低22.13）。

```bash
npm ci
cp .env.example .dev.vars
# 在.dev.vars填写服务端变量，禁止提交真实值
npm run dev
```

默认开发地址 `http://127.0.0.1:5173`，以终端实际输出为准。生产构建 `npm run build`，构建产物位于 `dist/`，可用 `npm start` 运行本地Worker预览。项目保留 Sites 的 Vinext / Cloudflare Workers 构建适配器；源码兼容React组件与Next App Router约定，运行时是Vinext。

## 服务端环境变量
| 变量 | 用途 |
|---|---|
| `FUYAO_TRANSPORT` | 默认 `mcp`，可显式设置 `rest`；真实证据显示实际传输及工具名 |
| `FUYAO_API_KEY` | 扶摇金融数据授权，生产通过托管Secret配置 |
| `AI_API_KEY` | 可选，语言模型服务授权 |
| `AI_BASE_URL` | 可选，OpenAI兼容接口根地址，默认 `https://api.openai.com/v1` |
| `AI_MODEL` | 配置模型时必填，不在源码中假定某个可用模型 |

本地变量放入被Git忽略的`.dev.vars`。生产变量必须配置在服务端，不能使用`NEXT_PUBLIC_`或`VITE_`前缀，不写入GitHub、前端或托管清单。当前部署已配置DeepSeek官方接口（deepseek-flash），完成本地真实模型调用验证。没有模型授权时，页面真实呈现“本地语义规则”；连接模型后，编译请求才会调用该服务。模型失败会显示错误，不静默生成正常结论。

## 核心架构与AI边界
| 模块 | 职责 |
|---|---|
| `app/page.tsx` | 中文网页版工作台、编辑、比较、本地保存和导出 |
| `lib/domain.ts` | 指标白名单、规则编译、冲突检测、三态筛选、波动率和快照差异 |
| `app/api/parse` | 服务端模型调用与结构校验；无授权时显式本地规则 |
| `lib/fuyao.ts` | 官方MCP/REST适配器、业务码、缓存、并发控制、财报/交易日历校验 |
| `app/api/market` | 限定研究池的金融数据入口，不接受任意上游URL |
| `lib/fixtures.ts` | 与真实股票隔离的构造样本和10个示例 |
| `lib/mcp-client.ts` | 官方Streamable HTTP MCP初始化、工具发现、只读调用 |
| `lib/experiments.ts` | 预期/实际对照、同快照敏感性和异常注入 |
| `lib/transfer.ts` | 同花顺条件表达、SuperMind脚本与可追溯导出 |
| `lib/diagnostics.ts` | 注入异常响应与构造样本的内置验证 |

规则先进行能力、单位与约束预检；AI核对条件并提供代理解释。模型输出不能遗漏、禁用、修改或新增预检条件；用户检查确认后，确定性引擎执行。没有任意SQL或代码执行功能。所有条件AND；冲突、未知字段、无穷值或空条件阻止筛选。明确失败优先于缺失，但全部逐条件证据仍保留。

## 真实数据来源和统计口径
优先使用题目推荐的 [扶摇 / 同花顺金融数据API](https://fuyao.aicubes.cn/docs/)。默认通过官方 `https://fuyao.aicubes.cn/mcp/a-share` 初始化、发现工具并只读调用；显式配置REST时才使用下列REST路径。已实测发现21项工具，当前没有账户自选写入工具。iFinD未接入，未用未经验证的其他行情源替换。

| 数据 | 官方接口 |
|---|---|
| 行情 | `/api/a-share/prices/snapshot` |
| PE/PB/PS/PCF、中文名 | `/api/a-share/valuations/snapshot` |
| 已披露财报 | `/api/a-share/financials/income-statements`，quarterly，最近8期 |
| 日线 | `/api/a-share/prices/historical`，1d，forward |
| 交易日历 | `/api/a-share/calendar/trading-days` |

默认研究池12只，可修改为1—20只标准A股代码。结果只代表该范围，不代表全A股；不做行业、ST、停牌和新股排除。默认代码用于提供可运行的固定研究范围，不构成推荐。

- 营收/归母净利润同比：最近可用已披露累计报告期与上年同期比较，非单季度环比；基数≤0或字段缺失时无法判断。
- 20日波动率：保守排除当日日线，使用前21个完整交易日的前复权收盘价，20个简单日收益率的样本标准差×√252×100；缺交易日不拼接。
- 行情/估值时间戳是响应批次最大有效时间，上游未提供逐股时间，不能保证逐股同等新鲜。页面展示获取时间、来源、单位、原始字段和请求ID。
- 行情依交易日历校验，交易时段/应有收盘时点滞后超过15分钟则标记过期。财报期末超过200天会提示核查。15分钟与200天为本产品质量规则，不是数据源服务承诺。
- 缓存：行情/估值60秒、财报6小时、历史/日历1小时；打开自动刷新后，每60秒在页面可见时尝试更新。缓存和上游延迟可能导致时点不变。
- 修改条件沿用同一快照；读取最新创建新快照，差异不再仅归因于条件。

## 指标与场景
支持15项指标：PE TTM、PB MRQ、PS TTM、PCF TTM、营收同比、归母净利润同比、最新价、当日涨跌幅、成交额（亿元）、成交量（万股）、振幅、20日年化波动率、20日涨幅、20日最大收盘回撤、20日均线偏离。
提供经营估值、低估值、现金流估值、成交活跃度、趋势回撤、增长质量6类模板。指标工具箱按4类组织，可直接加入可编辑条件，结果表自动展示本次策略使用的新增指标。

新指标沿用官方接口：成交额原始元值÷1e8，成交量股数÷1e4；振幅为(最高−最低)/前收盘×100。20日趋势使用此前21个完整交易日前复权收盘价，排除当日；最大回撤以正百分数表示，均线偏离为末收盘/末20个收盘均值−1。缺失或冲突不会补零，非正PS/PCF不作低估值证据。

## 已知边界和未做事项
1. 研究范围最多20只，非全市场；没有行业中性、ST/停牌过滤、历史估值或财报修订版本库。
2. 没有回测和后台定时监控；已完成比较、保存、条件差异作为题目要求的继续使用路径。
3. 保存仅浏览器localStorage，无账号、跨设备或服务端持仓。导出文件由使用者在数据授权范围内保管使用。
4. 上游批次时间不能证明每股独立新鲜度；财报披露日按接口契约解释，没有额外核对公告原文。
5. 内存缓存和限流为单Worker实例尽力实现，非分布式持久限流；正式大流量服务应增加网关配额。
6. 语言模型能力取决于实际配置；模型API未配置时不能将规则解析宣称为模型调用。
7. 同花顺当前提供条件复制与官方SuperMind脚本生成；没有执行账户写入，也未验证与PC/手机自选的同步关系。
8. 演示视频为可选交付，当前源码包含演示路径，尚未制作视频。

## 生产验收
仓库 Actions → **Production acceptance** → Run workflow，在GitHub运行器直接访问公开域名，检查15项能力与三组真实案例。无需配置额外Key，调用产品本身的服务端接口。产物`production-acceptance.json`只含条件、状态和证据追踪元数据；存在数据缺口会保留partial，不伪称全部字段通过。入口403/非JSON使任务失败，不能用发布成功替代生产端到端通过。

页面入口：**运行真实案例**，也可在**方法与口径**中运行。验收前可见固定研究池与条件；返回的验收标识可与服务端`mingce_acceptance`日志核对。
