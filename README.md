# 明策 MINGCE · 自然语言选股与策略解释器

把“经营改善、估值合理、走势相对稳定”转成可以检查、修改和执行的条件，展示股票为何入选、排除或无法判断，并解释条件变化的影响。

- **GitHub 源码：** https://github.com/lzy75/mingce-stock-lab
- **提交与演示指引：** [SUBMISSION.md](docs/SUBMISSION.md)
- **验收记录：** [FINAL_ACCEPTANCE.json](docs/FINAL_ACCEPTANCE.json)

## 已实现功能

| 功能 | 操作与产出 |
|---|---|
| 自然语言策略 | 输入偏好，AI澄清模糊词并生成可编辑的结构化条件 |
| 指标与场景 | 15项指标、6类研究场景，展示定义、单位、阈值与统计口径 |
| 确认与执行 | 条件编辑、单位校验与区间冲突检测，用户核对后执行 |
| 真实数据筛选 | 扶摇官方MCP读取用户研究池，自动分批、核对代码覆盖 |
| 可解释结果 | 入选、排除、无法判断三态名单；逐条件原始字段、来源、时间与请求ID |
| 条件影响 | 在同一快照调整阈值，查看新增、移出与条件敏感性 |
| 继续研究 | 比较2—4只股票、本地保存策略、导出名单与研究条件 |
| 同花顺接续 | 复制i问财表达、导出SuperMind研究板块脚本并校验创建后的回读 |
| 偏好与展示 | 场景模板、研究视图、响应式布局、蓝色与赭橙视觉和动效偏好 |
| 验证能力 | 构造示例、真实案例、边缘场景与100项自动测试 |

## 两分钟体验

1. 在输入框描述研究偏好，或选择预设场景，点击“用 AI 拆解我的策略”。
2. 核对代理定义、单位和阈值；按需编辑条件，确认后执行。
3. 查看三态结果，选择股票阅读逐条件证据；修改阈值查看同快照变化。
4. 勾选2—4只股票比较，保存策略或导出到后续研究工具。

真实案例：切换“真实数据”，输入“市盈率大于0倍，市盈率低于25倍”，核对条件后执行。2026-10-20公开网页实测为12只研究池、11入选、1排除、0无法判断，新快照与证据时间可查看。计数对应当次验收时点。

## AI、引擎与数据工具如何协作

| 层 | 职责 |
|---|---|
| AI | 理解研究意图、解释模糊词代理；输出经过结构与条件一致性校验 |
| 确定性引擎 | AND条件编译、单位校验、冲突检测、三态筛选、同快照名单差异 |
| 金融数据工具 | 官方MCP取数并保留原始字段、来源、时点、单位、口径与请求ID |
| 用户 | 核对代理定义、修改阈值、确认研究范围后执行 |

明确条件经过完整性校验，输入与数据质量检查分别在执行前和计算时生效。偏好推荐以可修改的研究条件模板呈现。产品围绕研究与证据解释设计，配有预测、收益承诺和买卖指令的输入检查。

## 本地运行

推荐Node.js 24；生成脚本的自动测试另使用Python 3。

```bash
npm ci
cp .env.example .dev.vars
# 在.dev.vars中填写服务端配置
npm run dev
```

默认地址为`http://127.0.0.1:5173`，以终端输出为准。`npm run build`构建到`dist/`；`npm start`运行本地Worker预览。技术栈为React、Vinext与Cloudflare Workers。

| 服务端变量 | 用途 |
|---|---|
| `FUYAO_API_KEY` | 扶摇数据授权 |
| `FUYAO_TRANSPORT` | 默认`mcp`；可显式选择`rest`，证据展示实际传输 |
| `AI_API_KEY` | 模型授权；线上使用DeepSeek官方服务 |
| `AI_BASE_URL` | OpenAI兼容服务根地址 |
| `AI_MODEL` | 实际配置的模型名称 |

授权存放于本机忽略文件或托管服务端Secret。公开网页已配置服务端授权，可直接体验。部署步骤见[部署指南](docs/DEPLOYMENT.md)。

## 指标、研究池与证据口径

通过[扶摇官方API/MCP](https://fuyao.aicubes.cn/docs/)读取数据。MCP端点为`https://fuyao.aicubes.cn/mcp/a-share`，执行初始化、工具发现与只读调用。

15项指标包括：PE TTM、PB MRQ、PS TTM、PCF TTM、营收同比、归母净利润同比、最新价、涨跌幅、成交额、成交量、振幅、20日年化波动率、20日涨幅、20日最大收盘回撤、20日均线偏离。

- 从12只起步研究池开始，可粘贴更多股票代码；每批20只，全部完成并核对覆盖后生成结果。
- 财报同比比较最近可用已披露累计报告期与上年同期；保留报告期、披露日和计算输入。
- 趋势指标使用此前21个完整交易日的前复权收盘，排除当日；年化波动率为20个简单日收益率的样本标准差×√252×100。
- 界面分别展示获取时间与上游批次证据时间，附带交易时点、财报有效性和字段质量检查。
- 行情/估值缓存60秒、财报6小时、历史/日历1小时；开启自动刷新且页面可见时每60秒尝试更新。
- 缺失、过期、冲突和不适用均进入数据质量判断；逐条件保留依据。同快照分析用于解释条件变化。
