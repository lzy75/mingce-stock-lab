# 构建前验收基线

在产品实现前建立 `tests/domain.test.mjs`。首次执行应因领域模块尚未实现而失败；实现后使用同一套用例复测。构造样本与真实行情隔离，所有构造样本名称与代码带有样本标识。

## 必须可操作的链路
输入 → 澄清/代理定义 → 编辑条件 → 冲突检测 → 明确确认 → 数据筛选 → 入选/排除/无法判断 → 原始证据 → 同快照条件差异 → 比较/本地保存/导出。

## 测试维度
1. 明确与模糊阈值、矛盾区间、空条件、未知字段。
2. 空值、空字符串、负PE、过期、冲突、21日样本门槛。
3. 业务错误不依赖HTTP状态：扶摇未带Key实测 HTTP 200 / code=2003；文档称code=2001。因此统一处理所有非零code。
4. 接口超时、限流、部分失败、错误JSON和结构不符均显示异常。
5. 只允许确定性AND条件；不支持的行业、新闻、预测等不能被静默丢弃。
6. 构造样本不能显示为实时；快照变化与条件变化分开解释。
7. 不输出确定性涨跌预测、收益承诺、直接买卖建议。
8. 网页复测键盘操作、窄屏、状态切换、比较、保存、导出以及异常入口。
