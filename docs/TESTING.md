# 测试说明

最终自动回归为100项，源码位于`tests/`；应用需Node.js 24，Python脚本测试需Python 3。测试使用构造样本或最小API替身，不依赖评审者账户，不调用交易接口。

## 覆盖范围

| 维度 | 主要覆盖 |
|---|---|
| 核心策略 | 模糊代理、显式阈值、条件编辑、AND逻辑、冲突区间、同快照差异 |
| 输入边界 | 空/超长输入、未知字段、错单位、附加未知要求、不支持窗口 |
| 数据质量 | 缺失、非正估值、过期、未来时点、重复冲突字段、财报披露日/报告期与同比基数 |
| 历史统计 | 21价格门槛、完整交易日、前复权、波动率、回撤时序、均线与涨幅手算 |
| 接口失败 | 非零业务码、HTTP错误、非法JSON、错误结构、限流、超时与无授权 |
| 大研究池 | 45只分3批、去重、完整覆盖、批次失败无部分正常名单、取消、旧请求隔离、429有界重试 |
| 产品输出 | 入选/排除/无法判断、证据按指标合并、比较、保存、旧条件不能导出新名单 |
| 合规与安全 | 不支持预测/收益承诺/买卖指令，注入拦截，构造数据不进入真实名单，跨站请求拒绝 |
| 生成脚本 | 创建与回读、重复执行、同名冲突、创建False、错/空回读、返回类型错误、查询异常 |
| 验收自身 | 错误HTTP不能被合法内容覆盖为通过；错误原因保留；独立报告目录可创建 |

构建前已定义主链路与异常基线，首次领域模块缺失时测试失败，随后使用相同用例回归。默认构造池12只的基线为4入选、5排除、3无法判断；构造数据均明确标记，不作真实股票展示。

## 可重复命令

```bash
npm test
npm run typecheck
npm run test:report
npm run security:check
```

`test:report`将完整TAP写到`artifacts/test-results.tap`。本地启动后可用`node scripts/check-web.mjs`检查HTTP边界，输出默认在`artifacts/`。真实探测需要服务端授权和网络：`node scripts/probe-mcp.mjs`、`node scripts/probe-web.mjs`、`node scripts/probe-data.mjs`；结果保持本地。

GitHub Actions的CI重跑自动测试、类型、构建和密钥扫描；Production acceptance从独立网络检查公开域名、真实模型/数据案例、HTTP边界和24只分批。它与用户实际浏览器验收分开记录，任一失败不被旧的通过结果覆盖。
