# 题目要求与功能对应

依据用户提供的《题目02｜自然语言智能选股与策略解释器》。原题作为产品验收依据，工具调用与仓库、网页操作授权来自用户对话。

| 原题要求 | 对应交付 |
|---|---|
| 自然语言澄清与可检查、可修改条件 | AI核对、模糊词代理解释、15指标字典、AND条件编辑与冲突检测 |
| AI、筛选引擎与金融工具职责明确 | README架构说明、模型结构校验、确定性筛选、官方MCP字段证据 |
| 真实候选与入选、排除解释 | 用户研究池、三态结果、逐条件排除统计与证据面板；公开网页实测 |
| 来源、时点、单位、口径与数据质量 | 原始字段、计算输入、请求ID、获取/批次时间、报告期与质量检查 |
| 条件变化的影响 | 同快照新增、移出与敏感性推演 |
| 比较、保存、回测或监控的继续使用路径 | 同快照股票比较、本地策略保存与导出 |
| 可访问可操作Web URL、仓库与README | 公开网页、GitHub源码、附件源码与启动说明 |
| AI使用与验证记录 | AI_USAGE.md记录协作任务、产出与验证方式 |
| 主链路、数据失败、极端与合规测试 | TESTING.md、tests/源码与100项自动回归 |
| 密钥、隐私与数据管理 | 本机忽略配置、服务端Secret、密钥扫描及匿名测试样本 |
| 研究定位及合规处理 | 模糊词澄清、证据展示、预测/收益承诺/买卖指令检查 |
