## 加分方向的准确边界
- 同花顺：扶摇官方MCP已经只读调用；当前工具清单没有自选账户写入能力。
- 提供问财条件复制、SuperMind官方custom_sector脚本生成与策略元数据导出；人工创建回读通过后，Codex又用官方Skill验证产品生成脚本的新建、重复执行和冲突拒绝。用户确认客户端无分组，客户端同步未通过；网页自动触发账户写入尚未实现。
- 不将以上加分项冒充原题必交项，优先保证核心筛选和异常兜底。

## 本轮先失败、再修正的回归
错误单位；已知指标后附加未知要求；非正PB和价格；同日未来时间；相同报告期/披露日冲突值。模型输出结构、显式条件一致性、非法请求和逐条件统计补充为回归检查。实际结果见test-results.tap和HTTP_VALIDATION.json。

## 本轮新增验收（导览、15指标与真实案例）
- 首屏导览直接使用同一份输入，场景切换即时更新明确标记的构造预览；进入研究台后调用真实AI，仍需核对条件再执行。
- 指标由7扩至15，沿用官方快照和完整交易日日线；所有新增指标都有统计定义、字段、单位和边界。
- 真实案例验收调用当前服务端模型及MCP，固定4只股票、3组策略；要求模型调用ID、有效证据追踪、计数守恒。负现金流估值属于不适用，不据此称低估。
- GitHub Production acceptance从独立网络验证公开域名，并保存可下载的机器报告；最新实际结果见DEPLOYMENT.md。未验证成功的线上或账户能力不记作完成。

生产主链路现已由GitHub独立运行器验证通过，服务端日志与下载报告的验收ID一致；生产浏览器点击验证仍受工具超时影响。同花顺网页自动写入尚缺远端执行授权和产品接续实现，不记为完成；已发现官方Skill通道，不能再描述为平台完全没有写入接口。
