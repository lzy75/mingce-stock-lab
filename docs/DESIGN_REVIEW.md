# 设计方向与复核

用户指定安装并参考 https://github.com/Leonxlnx/taste-skill ，已通过官方skill-installer安装为 `design-taste-frontend`。采用其app-screen路线，未将金融研究工具改为营销落地页。

## 方向
- 抽取：Accent ladder，seed 986203714，2026-10-19；保留用户明确的蓝色主调和少量赭橙。
- 选择原因：蓝色用于当前筛选、主数据和操作，淡蓝区分工作区域；橙色只标记需要判断的变化、异常和确认。
- 用户要求双重色彩，因此保留赭橙作为语义辅助，优先于技能的单强调色偏好。
- 保留三栏研究布局，左侧条件、中央候选、右侧证据，避免迁移框架或破坏已验证主链路。
- 产品特有元素：同一快照上的条件变化与三态证据，不制作装饰性假行情图。

## 每屏的问题
1. 工作台：哪些股票满足我确认的条件，证据是什么？
2. 策略推演：改一个阈值或使一个字段失效，结果如何变化？
3. 方法与口径：数字怎样计算，时点和能力边界在哪里？
4. 已保存：之前的研究条件是什么，如何继续验证？

## 视觉修正
- 更明确的研究蓝、亮白主面与高对比正文，减少细小英文标签。
- 收紧营销式标题和空白，让候选名单更早进入首屏。
- 研究视图提供日间/夜间、紧凑/舒展和动态开关，不改变筛选结果。
- 动态只表达操作反馈、计数变更、证据切换和滑块推演；无自动播放装饰、无延迟揭示关键数据。

## 检查方式
源代码使用技能lint；浏览器检查遵循当前环境要求，使用Codex浏览器工具，未运行技能自带的另一套浏览器自动化。按1440、768、390宽度检查，保留减少动态效果回退。只记录实际完成的检查，不声称未运行的inspect脚本通过。
