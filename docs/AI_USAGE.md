# AI使用与验证记录

## 使用方式

Codex参与需求拆解、领域逻辑、React界面、服务端接口、测试、联调、部署与文档整理；使用design-taste-frontend辅助既定蓝色与赭橙方向的设计复核。用户确认产品范围和设计方向，完成服务登录、密钥配置、SuperMind手动测试及公开网页最终验收。

产品内AI与开发AI分开：网页服务端使用已配置的DeepSeek模型核对结构化条件和解释代理定义；确定性引擎完成数值判断，扶摇MCP提供真实字段与追踪。模型不直接决定股票买卖。

## 实际发现与修正

| 问题 | 修正与验证 |
|---|---|
| 错单位、已知指标后附加未知要求可能被丢弃 | 预检阻止；增加单位与附加约束回归 |
| 模型可能增改、遗漏或禁用用户条件 | 输出结构与条件集合校验；默认模糊输入和显式条件实际调用模型验证 |
| 非正估值、未来时点、同披露日财报冲突可能误判 | 明确标为不适用/冲突；原始依据保留；边缘用例回归 |
| 平板布局溢出、重复策略输入、研究池20只限制 | 单一宽大输入与下方输出；调整响应式；完整研究池自动分批、覆盖校验、取消与有界限流重试 |
| 验收脚本的内容检查可能覆盖错误HTTP状态 | HTTP与业务结果同时成立才通过；失败摘要保留错误 |
| SuperMind创建后仅打印回读，缺少一致性约束 | 严格比对名称与代码；同内容不重复写入，同名不同内容拒绝覆盖；8项Python运行回归及真实远端测试 |
| 官方远端客户端证书链失败、沙箱拒绝getattr | 进程配置系统可信CA，未关闭验证；改用普通Series字段访问；重试成功 |
| CLI退出0但执行结果内含error | 检查错误字段和业务验证事件，不把进程退出码单独视为成功 |

没有将AI生成代码本身视为正确性证明；采用确定性测试、真实接口、远端执行及用户实际浏览器验收交叉验证。

## 最终结果与保留限制

100项自动测试通过，类型检查、生产构建与密钥扫描通过。用户在公开网页完成PE区间筛选并提供结果截图；不同网络的独立探测仍有超时/522，作为已知限制保留。SuperMind研究板块成功不冒充行情客户端或网页一键同步成功。
