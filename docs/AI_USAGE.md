# AI使用与验证记录

## AI Coding工作方式

Codex参与需求拆解、领域逻辑、React界面、服务端接口、测试、联调、部署与文档整理；使用design-taste-frontend辅助蓝色与赭橙方向的设计复核。用户确认产品范围和设计方向，完成服务登录与授权配置，并参与SuperMind和公开网页验收。

产品内AI与开发AI分别承担不同任务：网页服务端使用DeepSeek模型核对结构化条件并解释代理定义；确定性引擎完成数值判断；扶摇MCP提供真实字段与追踪。

## 实现与验证过程

| 工作内容 | 实现与验证 |
|---|---|
| 需求拆解 | 将自然语言、确认、筛选、解释、继续研究转为可验证任务，构建前定义主链路与异常用例 |
| 语义完整性 | 条件集合与输出结构校验；对显式阈值、模糊代理、单位与附加约束建立回归 |
| 指标质量 | 对估值适用性、未来时点、财报冲突和缺失字段进行三态判断，保留原始依据 |
| 交互与布局 | 单一大输入框和下方输出、响应式布局、分批研究池、进度与取消交互 |
| 接口验证 | 同时核对HTTP状态、业务结果和返回结构；测试限流、超时、跨站与无授权处理 |
| SuperMind导出 | 创建后严格比对名称与代码；同内容幂等，同名不同内容在写入前拒绝；8项本地脚本回归与官方远端验证 |
| 远端执行校验 | 使用系统可信CA、普通Series字段访问；检查执行结果中的业务验证事件 |
| 公开网页验收 | 用户完成真实输入、AI拆解、确认执行与新快照证据核对，并回传截图 |

验证结合确定性测试、真实接口、官方远端执行及用户实际浏览器操作，确保生成结果能被核对和复现。
